# AWS-genomics-analysis
This repository contains tutorials on how to use the services offered by Amazon Cloud for bioinformatics. SRR Storage and FASTQC Analysis.

This repository contains tutorials on how to use the services offered by Amazon Cloud for bioinformatics. The content includes:
-Setting up an Amazon account to use the console
-Using S3 buckets for sequence storage
 -Manual upload
 -Upload in AWS CLI
-Using ECL2 to obtain SRR sequences from NCBI
-Using ECL2 for sequence quality analysis.

All projects can be carried out using the free Amazon Cloud Services plan. Please note that you will be required to provide a credit card to authenticate your account in case you want to change your plan at any time. This does NOT mean that you will be charged for the services or your use of the console. 

TIP: Use a virtual card with a dynamic CVV, be safe!
